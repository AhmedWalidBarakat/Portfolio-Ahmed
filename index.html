PulseGuard

A predictive maintenance dashboard that forecasts equipment Remaining Useful Life (RUL) from sensor data (temperature, vibration, pressure) using a gradient boosting model, evaluated on machines never seen during training. Built for any organization that relies on monitoring critical infrastructure at scale, where catching wear early beats reacting to a breakdown.

AskLocal

A fully local, privacy-preserving RAG (Retrieval-Augmented Generation) chatbot built with LangChain, Ollama, and ChromaDB. It answers questions about your own PDF documents with grounded, cited answers — with zero external API calls, so nothing ever leaves your machine. Built for any organization that can't send sensitive or confidential documents to the cloud.

A computer vision safety compliance monitor that detects people in a photo using YOLOv8 and flags whether each is wearing a hard hat and high-visibility vest, using OpenCV color analysis. Built for organizations where catching a missing hard hat or vest early is a top operational priority.
